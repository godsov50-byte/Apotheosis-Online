## Tier and mode boundaries

There is no universal rule that an ordinary practitioner's Tier must equal a technique's Tier. Actual prerequisite conditions govern ordinary use. Azimah manifestations are a specific source restriction: existing body-Tier techniques at BASE only, normal costs and daily limits; no artificial AP or surge. Generic F11 enhanced/surge benchmarks are not evidence that every technique supports those modes. A profile must explicitly permit each mode and define its effect.

## Failure, counters and mastery

Wrong affinity access, inactive required channel, missing prior acquisition, forbidden acquired family or insufficient specific mastery rejects before effect commitment. Preparation, activation and sustain are distinct phases; legitimately completed preparation is not refunded merely because a later phase fails. An alias or second stored object shares the same daily family counter. F63's learned execution stage depends on qualifying attempts, successes and contexts, not a narrative claim of mastery. Replay IDs bind the full payload, so changing a profile or payer under an old request cannot grant free execution.
